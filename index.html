使用说明
  1. 在浏览器中登录 ChatGPT 网页版
  2. 访问 https://chatgpt.com/api/auth/session 获取 Session JSON
  3. 将 JSON 粘贴到左侧「源 JSON」输入框（自动转换）
  4. 检查右侧生成的「目标 JSON」
  5. 点击 「复制」或 「下载」保存为 auth.json
安装说明 · auth.json 放置位置

下载后将 auth.json 放置到以下路径：

# Linux / macOS： ~/.codex/auth.json # Windows： %USERPROFILE%\.codex\auth.json

如果 .codex 目录不存在，请手动创建。放置完成后，运行 codex 命令即可自动读取认证信息。

🔐 安全提示 auth.json 包含你的 OpenAI 会话凭证，请勿分享给他人，也不要上传到公开的代码仓库。建议将 .codex/ 添加到 .gitignore。
